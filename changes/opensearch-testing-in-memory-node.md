**`@ddd-ts-kit/opensearch/testing` exports an OpenSearch in memory and a local node for tests.** `InMemoryOpenSearch` is an `OpenSearchTransport` that serves the subset of the REST API `OpenSearchReadModelStore` calls (strict mappings, aliases with a filter and a routing, conditional writes, the query DSL the store writes), the fake the package runs its own specs on: handed to the store, it holds an adapter to `readModelRowsContract` and `criteriaContract` in a unit spec with no server. `OpenSearchServer` serves the same node on a local port, behind the credentials of the security plugin, for a spec that goes through `fetchTransport`. A spec on a real node still proves what the fake answers differently. See the README of the package, "In the specs of a project", and `docs/tools/search-read-models.md`.

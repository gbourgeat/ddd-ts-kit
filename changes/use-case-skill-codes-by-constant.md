**The `use-case` skill has a route declare its error codes by the members of the code lists.** It tells the agent to write `errors` of a route with `<Context>Codes.<Refusal>` for a refusal of the context and `KitCodes.<Code>` of `@ddd-ts-kit/kernel` for a code of the kit, never as a string, so that the editor completes the code and a typo does not compile; under `"stack.refusals": "factories"`, where no list holds the codes of the context, they stay strings and only the codes of the kit are named by `KitCodes`.

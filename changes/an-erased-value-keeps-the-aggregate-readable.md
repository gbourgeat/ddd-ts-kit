**A personal value read as a date or a value object keeps the aggregate readable once its subject is erased.** `StoredEventData` gains `personalText(field)`, `personalInstant(field)` and `personal(field, read)`, which answer `undefined` when the field is absent or its subject was erased, and never hand `ERASED_PERSONAL_DATA` to `read`; `isErased(field)` says whether it was. `optionalInstant` reads an erased date as absent. A sealed date read with `data.instant`, or an address parsed by a value object in `decode`, used to refuse `[erased]` with an `UnreadableEventError`, so the aggregate no longer loaded after the erasure of its subject.

To move: a `decode` that reads a personal value with `data.text`, `data.instant` or a value object reads it with `data.personalText`, `data.personalInstant` or `data.personal(field, ValueObject.of)`, and the field of its event admits `undefined`.

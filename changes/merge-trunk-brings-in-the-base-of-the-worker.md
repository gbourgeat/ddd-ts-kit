**`ddd-ts-kit merge-trunk` without `--trunk` brings in the base of the worker of the worktree.** It read `origin/HEAD`, then `origin/main`, whatever `.ddd-ts-kit/worker.json` named as `base`, the ref `worker-scope` cut the branch from, where `verify-merge` already reads it: a worker cut from another branch than the default one was given the default one. `--trunk` still names any other ref. When the branch is up to date with that base while the default trunk holds commits it lacks, the answer says so and gives the command that brings it in, so that a worker cut from the branch of another one, or scoped again on its own branch, does not read "up to date" as "holds the trunk".

To move: a worker stacked on the branch of another worker has that branch as its base. Once that branch landed, name the trunk: `npx ddd-ts-kit merge-trunk --trunk origin/main`.

**`@ddd-ts-kit/eslint-plugin` reads `shared/` and the test folder of a module as the CLI does.** In a context divided into modules, a file of `<module>/test/` is a test of that module, and a file of `shared/infrastructure/`, `shared/presentation/` or `shared/test/` is read in its layer, with no module. The preset counts `<contexts>/*/*/test/**` among the test files. Nothing changes for a project as it is laid out today: this is the layout to come, which the CLI reads since the previous step.

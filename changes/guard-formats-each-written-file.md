**The guard of the plugin lays out each written file with the Biome of the project before it checks it, when the config says `"formatOnWrite": true`.** The `PostToolUse` hook runs `node_modules/.bin/biome format --write <file>` on the file a session just wrote (TypeScript, JavaScript, JSON; the binary of the project only, never `npx biome` nor another formatter), then the per-file check as before, so that the layout is settled at the write and the lint findings that follow a wrapped line come back in the same hook output. A Biome that is not installed, or that fails, changes nothing. The key is read as `true` only; absent, the hook formats nothing, as before (`docs/CONFIG.md`, "Working agreements"). From the AI-native SDLC playbook of Anthropic (hooks as build-time guardrails).

To move: set `"formatOnWrite": true` in `ddd-ts-kit.config.json` of a project whose `format` script runs Biome.

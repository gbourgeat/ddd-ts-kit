**The descriptions of the skills fit the listing budget of Claude Code, so every skill keeps its triggers.** Claude Code loads the name and description of every skill into each session within 1% of the context window (about 8,000 characters on a 200k window) and, when the listing overflows, drops the descriptions of the skills invoked least: the 26 descriptions of the plugin took 13,853 characters, so on a 200k window some skills stopped triggering on their keywords. Each description now opens with its trigger ("Use when ..."), keeps the words a user says for it and leaves the pointers to other skills to the body: 7,489 characters for the 26, from 259 to 355 each, and the 6 agents from 2,768 to 2,166 characters. A test of the plugin (`node --test plugin/skills/descriptions.test.mjs`) fails on a skill or agent description over 400 characters, or on 26 skill descriptions over 8,000 together, and names them.

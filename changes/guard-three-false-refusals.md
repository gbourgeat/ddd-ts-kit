**The guard of the plugin no longer refuses three commands a worker may run inside its scope.** A folder of its context is moved, removed and copied into (`git mv <folder>`, `mv`, `rmdir`, `rm -r`, `cp file <folder>/`): the guard took a folder for a file with another name (a hard link), since a folder counts more than one link. The schema of a query string, `presentation/http/<resource>/<use-case>/*.query.ts`, is written by hand as `docs/ARCHITECTURE.md` says: only `application/queries/**/*.query.ts` is sent to `generate query`. And the words of the command behind a package runner (`npx`, `pnpx`, `bunx`, `npm exec`, `pnpm dlx`) are read as the shell split them, so `npx ddd-ts-kit generate value-object invoicing SupplierName --term "SupplierName=le nom d'un fournisseur"` is no longer refused as a quote that never closes, nor a `>` or a `;` inside a quoted word read as a redirection or a second command; the string of `-c`/`--call`, of `env -S` and of `su -c` is still read as a command line.

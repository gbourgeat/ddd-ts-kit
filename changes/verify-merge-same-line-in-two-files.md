**`ddd-ts-kit verify-merge` no longer reports as lost the same line, or the same test title, that each side removed from a different file.** Lines and titles are counted over all the files of a merge as one set, so that a line moved to another file is not lost; counted that way, two removals of one text by the two sides counted once. The same generated marker (`// TODO(domain): ...`, an `it.todo`) filled in one file by the branch and in another by the trunk was reported as a loss tagged `(both)`. A line is now expected no more often than its files expect one by one.

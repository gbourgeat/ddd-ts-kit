**With the identity preset and tenants, a request names the organisation it works in.** The preset gives the HTTP boundary of the project (`http-boundary.ts`) `resolveTenant: firstTenantOf(tenantFromHeader(), tenantFromClaim())`: a person of several organisations names one with `x-tenant-id` on each request to the data of a tenant, a person of one works in it as before, and a header naming an organisation the person does not belong to is refused with 403 at the edge. A boundary that resolves its tenant already is left alone; one the team rewrote gets a step saying what to add.

To move: a project bootstrapped with `--preset identity` and tenants before this version adds `resolveTenant: firstTenantOf(tenantFromHeader(), tenantFromClaim())` to the object `httpBoundary` returns, and `readonly resolveTenant: TenantResolver` to `HttpBoundary`, the three functions and the type imported from `@ddd-ts-kit/http`.

**The behaviour pages no longer show a format placeholder in a heading or a rule.** A spec written with `describe.each(...)('AppointmentExportGateway, %s', ...)` or `it.each(...)('refuses %s with 422', ...)` put `%s` in `docs/behaviour/<context>.md`, where the reader could not tell what it stood for. The page now writes `AppointmentExportGateway for each case` (the text before a placeholder that follows a comma, trimmed of it), `refuses each case with 422` and `The occupancy read from each case` when the placeholder is part of the sentence, and `each case, by cause` for a title that opens with it; `%s`, `%d`, `%i`, `%f`, `%j`, `%o`, `%O`, `%p` and `$name` are read this way. The cases themselves are not read: they are known when the spec runs.

To move: run `ddd-ts-kit docs --behaviour` and commit the pages.

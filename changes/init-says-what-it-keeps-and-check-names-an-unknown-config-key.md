**`init` says what it keeps on a combination its defaults would not choose, and `check` names a key of the config file the kit does not read.** `init --orm none --audit on` and `init --http none --forms on` exit 0 as before, and now end with a note: the entries of the audit trail live in the memory of the process until `src/platform/audit/create-audit.ts` gets an adapter of your storage; no route serves a form until an HTTP framework is chosen. A key of `ddd-ts-kit.config.json` the kit does not read, at the root (`"contextDir"`) or under `stack` (`"ormm"`), was ignored without a word; `ddd-ts-kit check` reports it as `config/valid` on its line, with the nearest key the kit reads (`contextsDir`, `stack.orm`) or the advice to remove it.

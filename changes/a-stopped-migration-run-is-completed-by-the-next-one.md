**`drizzle-generate`, `prisma-generate` and `typeorm-generate` add the append-only guard of the audit trail on every run.** A run stopped after the tool of the ORM wrote its migration and before the guard was added left the audit entries open to UPDATE and DELETE, and the next run found nothing to write. The next run now adds the guard to the migration that creates the audit entries, whatever it writes itself. The repair reaches the latest migration of the project only: an older one may be applied already, so it is left as it is and named in one line when it lacks the guard.

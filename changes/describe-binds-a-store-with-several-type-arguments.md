**`ddd-ts-kit describe` and the "Ports" section of `CONTEXT.md` show as bound a port whose adapter extends a parent with several type arguments.** An adapter declared `class DrizzleAppointmentList extends DrizzleReadModelStore<AppointmentRow, PgQueryResultHKT> implements AppointmentList`, as a Drizzle or a Prisma read model store is, was not read as an adapter, so its port was listed `not bound` while the application ran with it. The parent is now whatever stands before `implements`, on one line or on the lines the formatter gives a long heritage. A port file that declares an interface before its abstract class is named after the abstract class, which is the injection token.

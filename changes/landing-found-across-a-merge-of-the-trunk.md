**`ddd-ts-kit merge-trunk` finds where a branch landed when the branch had merged the trunk before its squash.** Between two commits of the branch that carry the same patch, the newer one was taken only when the trunk held every file that differs between them. Across a merge of the trunk those are the files the merge brought: one more change of the trunk to any of them and the base fell back before that merge, so the lines of the trunk read as the branch's own and came back as conflicts. Only the files where that merge differs from the trunk commit it brought in are compared now.
